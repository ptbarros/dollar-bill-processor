Download & Install

Pick your operating system below. Every build is free and runs entirely on your own computer.

Heads-up: Dollar Detective isn't code-signed (a signing certificate is an expensive yearly cost for a free hobby project), so Windows and macOS show a one-time "unknown developer" warning on first launch. It's normal for small open-source apps — the steps below get you past it. As always, only run installers from the official Releases page.

2. Install it

Run the downloaded .exe. It installs just for you — no administrator password required.

3. Get past the SmartScreen warning

Windows may show "Windows protected your PC." Click More info → Run anyway. This appears only because the app isn't signed, not because anything is wrong with it.

macOS (Apple Silicon)

For Apple-Silicon Macs (M1, M2, M3, M4…). Intel Macs aren't currently built.

Download the .dmg

1. Install it

Open the .dmg and drag Dollar Detective into your Applications folder.

2. Get past Gatekeeper (first launch only)

Because the app is unsigned, double-clicking it the first time may seem to do nothing. Do one of these, once:

  • Right-click the app in Applications → Open → confirm Open in the dialog, or
  • Run this in Terminal (adjust the path if you didn't move it to Applications):
xattr -dr com.apple.quarantine "/Applications/Dollar Detective.app"

After that first launch, it opens normally like any other app.

🐧 Linux

Portable AppImage — no install, runs on most x86-64 distributions.

Download the AppImage

Make it executable and run it

chmod +x DollarDetective-x86_64.AppImage
./DollarDetective-x86_64.AppImage

If you get a FUSE error

Run it in extract-and-run mode instead:

./DollarDetective-x86_64.AppImage --appimage-extract-and-run

↩️ Trouble after an update?

If a new version won't open or starts misbehaving, you can go back to the previous one — no need to get into the app first.

If the app does open, the easiest way is inside it: Help → Revert to Previous Version. If it won't open, reinstall the older version by hand:

  1. Open the releases page and pick the version you had before.
  2. Download the same edition you normally use — the standard Windows -setup.exe (or the DirectML / NVIDIA build), the macOS .dmg, or the Linux .AppImage.
  3. Run it. It installs right over the current version — no need to uninstall first.
Open the releases page
Your work is kept. Your patterns, settings, labels and saved results live in your user folder, separate from the program, so reinstalling an older version leaves all of it in place. On Windows you'll get the same one-time SmartScreen prompt as any install.
